-----------------------------------
홈페이지 실행에 필요한 준비물:
-----------------------------------

이 홈페이지를 로컬에서 확인하거나 변환 스크립트를 실행하려면
먼저 Python이 설치되어 있어야 합니다.

Python이 설치되어 있지 않다면 아래 공식 사이트에서 최신 버전을 내려받아 설치하세요.
설치 과정에서 "Add Python to PATH" 옵션 체크를 권장합니다.

https://www.python.org/downloads/


-----------------------------------
홈페이지를 로컬에서 보려면:
-----------------------------------

본 홈페이지는 SPA(Single Page Application) 방식으로 제작되어 있어
로컬 환경에서는 기본적으로 정상 동작하지 않습니다.

로컬에서 확인하려면 _Local 폴더의 모든 파일을 복사해
홈페이지 폴더 안의 기존 파일에 그대로 덮어쓰면 됩니다.
이렇게 하면 SPA 구조 대신 iframe 방식으로 정상 동작하게 됩니다.

또한 본 홈페이지의 모든 원본 페이지는 마크다운 문서입니다.
전체 페이지를 완전한 HTML 형태로 보려면 아래 스크립트를 실행하세요.

---------------------
python local.py
---------------------


-----------------------------------
깃허브에 업로드하려면:
-----------------------------------

업로드용 HTML 프래그먼트를 생성하려면 아래 명령어를 실행합니다.

---------------------
python builder.py
---------------------

이 명령어는 모든 마크다운 문서를 변환하여 _Upload 폴더에 HTML 조각으로 생성합니다.
업로드할 때는 _Upload 폴더의 내용과 Images 폴더를 함께 업로드하시면 됩니다.

참고로 _Local, _Server처럼 이름이 밑줄(_)로 시작하는 폴더는 자동 변환 대상에서 제외됩니다.
Images 폴더는 제외 대상은 아니지만, 변환 대상인 마크다운(.md) 파일이 없으므로 별도로 변환되지 않습니다.


※ 모든 스크립트는 Python 3.14에서 제작 및 테스트되었습니다.
